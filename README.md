# 🎬 Streamflix - Frontend

Streamflix is a Netflix-inspired full-stack movie streaming web application developed as part of my **MERN Stack Training at CodeSquadz**. This project was built to gain hands-on experience in creating responsive user interfaces, integrating REST APIs, implementing authentication, and deploying a production-ready web application.

The frontend is developed using **React** and **Vite**, providing a modern, responsive, and fast user experience.

---

## 🚀 Live Demo

🌐https://stream-inn.netlify.app/
---

## 📌 Project Overview

Streamflix provides users with a clean and responsive interface where they can create an account, log in securely, and browse streaming content. The project focuses on frontend development, API integration, authentication flow, and responsive UI design.

This application communicates with a Node.js + Express backend hosted on Render and uses MongoDB for data storage.

## ⚙️ Installation

Clone the repository

```bash
git clone <frontend-repository-link>
```

Move inside the project

```bash
cd streamflix-frontend
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file and add

```env
VITE_API_BASE_URL=https://your-render-backend-url/api
```
